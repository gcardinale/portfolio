## Contesto

Azienda del settore trasporti e logistica con una piattaforma di gestione integrata e tracciamento blockchain. Ho ricoperto il ruolo di IT Manager e Software Architect: responsabile dell'infrastruttura IT aziendale e architetto del software della piattaforma.

## Sfida

Portare l'azienda su un'infrastruttura cloud coerente e governata — autenticazione centralizzata, posta, accessi — e allo stesso tempo evolvere la piattaforma applicativa: UI transazionali complesse, integrazioni esterne (PEC, fatturazione elettronica), logiche di business per imponibili e specifiche di trasporto.

## Cosa ho costruito

- **Infrastruttura Microsoft Azure realizzata da zero**, inclusa l'autenticazione centralizzata via Azure AD / Microsoft Entra ID per mail e accessi cloud di tutta l'organizzazione.
- **Componenti UI Blazor complessi**: griglie dati con infinite scrolling e filtri dinamici, form transazionali, visualizzazione condizionale in base allo stato degli ordini; migrazione di componenti da tecnologie legacy.
- **API REST documentate** via Swagger, con integrazioni esterne: PEC, mail transazionali, fatturazione elettronica in cloud.
- **Gestione utenti e policy di accesso** con ruoli specifici (operatore remoto, shipper direzionale), logiche di business per il calcolo degli imponibili e le specifiche di trasporto.
- Integrazione di **librerie UI enterprise** (Syncfusion, FluentUI), refactoring, ottimizzazione delle query, gestione della configurazione multi-ambiente.

## Stack

Blazor + ASP.NET, Entity Framework, API REST (Swagger), Azure end-to-end, Microsoft Entra ID, Syncfusion / FluentUI.

## Risultati

- Organizzazione interamente su Azure con single sign-on aziendale (mail e accessi cloud) dove prima non esisteva un'infrastruttura centralizzata.
- Piattaforma applicativa evoluta su componenti UI ad alta complessità e integrazioni esterne critiche (PEC, fatturazione) in esercizio.
